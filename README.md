# Public Records Search Portal (PRP / Miami-Dade)

A static, single-page launcher for Florida DEP **Petroleum Restoration Program (PRP)** records and related
Miami-Dade County public records. Enter a DERM work group number, an FDEP Facility ID (FACID), an ERIC ID,
a facility name or "Sunshine #", a folio, or an address. The app builds one-click links to the right
FDEP and county searches and reports.

> Not an official FDEP or Miami-Dade County application. Stored data is a convenience snapshot. Always
> confirm in the official systems before a file review.

## Features

**Search inputs**
- **DERM work group** (AG, ARP, HWR, IW, IW5, SW, UT plus a number): Miami-Dade ECM/CARA and PEN-R, plus the FACID and folio buttons below when the work group maps to them.
- **FDEP Facility ID** (7 digits, or 9 digits with the county prefix): the full FDEP button stack (below).
- **ERIC ID**: FDEP Information Portal.
- **Find Facility by Name / Sunshine #**: searches the stored Miami-Dade list. A **"Not listed? Search all Florida in FDEP STCM"** button covers everything else.
- **Folio / address**: Property Appraiser, ECM/CARA by folio, DERM Environmental Considerations map, Google Maps and Google Earth.
